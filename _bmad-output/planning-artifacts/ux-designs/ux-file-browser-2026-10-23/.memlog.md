- (decision) Stakes: internal-grade tool built to production-quality standards; evaluated for a course; intended for daily developer use. Working mode: fast path (user asked to draft both spines directly).
- (decision) Primary user: developer in a terminal (e.g. with Claude Code) who needs a lightweight companion to inspect project file structure and preview generated files without launching an IDE; also a general-purpose local folder previewer.
- (decision) Preview types: Text, Markdown, PDF, DOCX, Images, plus a Metadata card for unsupported binaries.
- (decision) Layout: classic 2-pane, hierarchical folder tree left, preview right, clean resizable divider. Form-factor: desktop web (browser).
- (decision) Tree: snappy, lazy directory expansion. Dotfiles shown by default at opacity 0.6.
- (decision) Persistent minimal header/toolbar: folder picker, dotfile toggle, manual refresh, theme selector, active-file 'Last modified: ...' timestamp.
- (decision) Visual: vanilla CSS with custom properties only (no UI framework, no Tailwind); restrained typography/spacing; maximize horizontal room for content. Themes: Light (crisp editorial white/gray), Dark (sleek developer), Warm Sand (low-glare warm earthy neutral).
- (decision) States: welcoming empty states for no-folder-open and empty-folder; >1 MB text shows elegant truncation warning banner; unsupported binaries show polished Metadata Card, never a raw error.
- (decision) Sandboxing: zero external network calls and no remote asset icons (inline SVG only, per AGENTS.md).
- (assumption) Project constraints from AGENTS.md apply: read-only file access, single-item selection, client-side sort/filter, FileRow role=option/aria-selected/tabIndex/Enter+Space, list role=listbox, previews keyboard-reachable.
- (decision) Sources extracted: brief.md, addendum.md, prd.md (final 2026-10-23). Spines cite PRD IDs (FR-n, NFR-n, UJ-n) verbatim; named journeys UJ-1 and UJ-2 are mirrored.
- (assumption) [ASSUMPTION] 'Last modified' stamp placed in the Preview Header (PRD FR-11), not the global toolbar as the brain dump said. Rationale: it describes the active file. Needs owner confirmation.
- (assumption) [ASSUMPTION] Folder tree a11y: AGENTS.md mandates listbox/option on FileRow, but PRD FR-8 needs expanded state, which listbox cannot express. UX spec states the required behavior (arrow expand/collapse, announced expanded + selected) and flags the role choice as an open item for architecture/owner; AGENTS.md is not changed by UX.
- (assumption) [ASSUMPTION] No user-facing sort/filter controls in v1 (PRD FR-4 fixed folders-first alpha order); types.ts SortField/FILE_CATEGORIES not surfaced. Search out of scope.
- (assumption) [ASSUMPTION] 'Truncation banner' realized as an inline notice banner at the top of the text preview (PRD says visible notice, FR-12). Markdown over 1 MB unspecified: treat the same as text.
- (assumption) [ASSUMPTION] Metadata Card covers unsupported binaries, zero-byte files (labelled empty), legacy .doc, unknown types and render failures (with a short explanation) per FR-17/FR-18. Images are previewed, not carded.
- (assumption) [ASSUMPTION] Fonts are system stacks only (no web fonts, per NFR-5). Theme control is a segmented 3-way control. Open-folder prompt is the sole content before a folder is chosen (FR-25). Unsupported browser gets an explanatory screen (NFR-9).
- (assumption) Gap noted: PRD UJ-1 says node_modules is 'visually recessive' but no FR dims it; only dotfiles are dimmed. Keep to dotfiles only unless owner says otherwise.
- (override) Dotfile dimming: opacity 0.6 at rest only; returns to 1.0 while a dotfile row is hovered or selected/active (guarantees WCAG AA in Warm Sand). Resolves the contrast [NOTE FOR UX].
- (decision) Last-modified stamp lives in the Preview Header (confirmed by owner; supersedes the toolbar placement in the brain dump).
- (override) Tree a11y: use role=tree / role=treeitem with aria-expanded, aria-selected (owner decision). Supersedes the listbox/option policy in AGENTS.md for the tree; AGENTS.md itself is not edited by UX and needs a follow-up update by the owner/architecture before implementation.
- (decision) Dimming rule scoped strictly to entries whose name starts with '.' (files and folders). No hardcoded folder names such as node_modules in v1.
- (decision) Text types: extensions like .gitignore, .env and extensionless plain config files are recognized and previewed as plain text.
- (decision) Divider bounds: tree pane min 220px, preview pane min 320px.
- (decision) Text wrapping: standard soft wrap for plain text and Markdown previews (no horizontal scroll by default).
- (decision) Scroll on Refresh: preserve the preview pane scroll position when the selected file path is unchanged.
- (decision) Extensionless text recognition: static lookup of well-known file names (Makefile, Dockerfile, LICENSE, README, .gitignore, .env, etc.) treated as plain text; no content sniffing, stays within PRD FR-17.
